2025.09 - 현재
기술스택

주요역할 및 기능

1) 서비스 운영

  • 업무 시스템 WEB/WAS·PostgreSQL 운영, 외부 연동용 Nginx 리버스 프록시 구성
  • 수동 실행하던 백엔드의 systemd 서비스 전환, 재부팅·장애 뒤 자동 재시작
  • 스크립트 역할별 이관 시 하드코딩 경로·SELinux 문제 정리, 방화벽 실행·영구 설정 일치 확인
  • 디스크 사용률 96%에서 점유 원인 분류 후 오래된 DB 백업 정리로 73%

2) 백업 구축

  • 애플리케이션·홈·설정 경로의 restic 암호화 증분 백업 (매일 새벽, 클라우드 저장소)
  • DB 덤프 재다운로드·바이트 단위 비교와 실패 시 메일, 구축 시 새 DB 복원 시험

3) 백업 재점검

  • 한 달 반 뒤 스크립트·문서를 실제 로그·저장소·디스크와 대조
  • 잠금 충돌 시 로그 없는 정상 종료, 날짜를 보지 않는 상태 검사 발견
  • 2027년 3월쯤 Git 미러 백업을 멈추게 할 임시 파일명 누적 버그, 알림 상태·DB 설정 파일의 백업 누락 발견과 수정안 정리
